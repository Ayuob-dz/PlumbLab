PlumbLab — Plumbing & Gas Learning Simulator
A responsive multilingual (Arabic/French/English) educational web prototype.
Run locally
Extract the ZIP.
Open the folder in VS Code.
Start a local web server (for example, the VS Code Live Server extension).
Open index.html through that local server.
The 3D view uses Three.js from a CDN, so an internet connection is needed when running the prototype.
Deploy free
Upload the project files to a GitHub repository and enable GitHub Pages from Settings → Pages. Keep index.html, style.css, and app.js at the published root.

Important scope and safety
This is a schematic learning prototype, not an engineering drawing or installation guide. Gas content is limited to general safety awareness. Real gas work, commissioning and leak testing must only be performed by qualified professionals under applicable local rules. Do not use the 3D model to plan or perform real installations.
