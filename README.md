# PlumbLab V4 — Realistic Bathroom Workshop

منصة تعليمية تجريبية متعددة اللغات (العربية والفرنسية والإنجليزية) للتعرف على مكونات التركيب الصحي عبر ورشة ثلاثية الأبعاد.

## الجديد في V4

- تطوير شكل الحمّام المفتوح: جدران مبلطة، نافذة، مرآة، حوض، مرحاض، منطقة دش وتفاصيل إضافية.
- فصل الجدران عن بقية التجهيزات وإمكانية إظهارها وإخفائها.
- وضعان للتعلم: جولة موجهة بأربع خطوات، واستكشاف حر.
- زوايا كاميرا جاهزة: أمامية وعلوية، مع إعادة ضبط المنظور.
- إطار توضيحي حول العنصر الذي يختاره المتعلم.
- الحفاظ على طبقات الماء البارد والساخن والصرف والتجهيزات والقطع.
- الحفاظ على مكتبة القطع والدروس والاختبار والتقدم المحلي.
- ترحيل تقدم الدروس السابق من مفتاح v3 عند توفره.

## التشغيل

1. فك ضغط الملف.
2. افتح مجلد `plumber_simulator` في VS Code.
3. شغّل `index.html` باستخدام إضافة Live Server أو خادم محلي مشابه.
4. يلزم اتصال بالإنترنت لتحميل Three.js وOrbitControls والخطوط من CDN.

## التحكم

- اسحب داخل المشهد لتدوير الكاميرا.
- استخدم عجلة الفأرة أو إيماءة القرص للتقريب والإبعاد.
- اختر وضع التعلم الموجه للتنقل بين الخطوات، أو الاستكشاف الحر.
- استخدم أزرار الطبقات لإظهار وإخفاء الجدران وشبكات المياه والصرف والتجهيزات.
- اضغط على عنصر في المشهد لعرض وصفه.

## النشر المجاني

يمكن نشر محتويات المجلد على GitHub Pages دون خادم خلفي.

## الحدود والسلامة

النموذج ثلاثي الأبعاد تمثيل تعليمي مبسط وليس تصميماً هندسياً أو مخطط تنفيذ أو مرجعاً للأبعاد والميول والأقطار. لا يستخدم لتحديد طريقة التركيب الفعلية. محتوى الغاز للتوعية العامة فقط؛ يجب أن ينفذ مهني مؤهل جميع أعمال الغاز والتركيب والتشغيل والفحص وفق القواعد المحلية.

## فحوصات هذه النسخة

- تم التحقق من صياغة JavaScript باستخدام `node --check`.
- تم تحليل بنية HTML بنجاح.
- يلزم اختبار بصري تفاعلي على متصفح الهاتف والحاسوب للتأكد من الأداء الفعلي واكتشاف أي اختلافات في الأجهزة.
