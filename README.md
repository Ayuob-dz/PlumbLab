# PlumbLab v3 — Learning Workshop

A responsive, multilingual (Arabic/French/English) learning prototype for plumbing concepts.

## v3 improvements
- Expanded bathroom workshop with distinct cold, hot, drainage, fixtures and fitting layers.
- Interactive schematic elbow, tee, reducer and trap models.
- Searchable parts library.
- Lesson completion tracking and a local progress indicator (stored only in this browser using localStorage).
- Five-question knowledge check with immediate feedback and score.
- Keyboard focus styles and mobile-friendly controls.
- Arabic RTL and French/English LTR layouts.

## Run
1. Extract the ZIP.
2. Open `plumber_simulator` in VS Code.
3. Start `index.html` with Live Server or another local static server.
4. Internet is required for Three.js and OrbitControls CDN imports.

## Publish free
Publish the folder contents using GitHub Pages. No backend or paid database is required for this prototype.

## Important limits
All 3D geometry and routes are schematic learning illustrations, not construction plans, dimensions or installation instructions. The gas section is awareness-only. Real plumbing work and all gas installation, modification, commissioning or testing must be performed by a qualified professional under local rules. If a gas leak is suspected, move away and contact the appropriate emergency or qualified service.
